1. WHAT "PREMIUM" MEANS HERE (distilled from the references)
--------------------------------------------------------------------------------
BDB:
- Each section owns ONE solid field (ink / paper / pink). No gradients, no glass.
- Huge condensed uppercase display + quiet serif counter-line underneath.
- Tag buttons: rectangular, tight padding, text sits on a solid chip.
- Edge-to-edge media columns; text never floats on busy photos.
Rolex:
- Media is cinematic: full-bleed, generous crop, slow scale (1.08 -> 1.0)
  while entering, dims slightly while leaving.
- Tiny uppercase kicker above a big calm headline, lots of air.
- Motion is slow and exact: 700–1200ms, expo/quart easing, never bouncy.
- A visible "Reduce motion" switch in the footer.
Combined rule: loud typography, quiet motion, rich media, strict grid.

2. DESIGN TOKENS (keep, refine only)
--------------------------------------------------------------------------------
Colours: ink #0F1230, paper #F7F4EC, pink #F3C3CF, pink-deep #E9A3B5,
         navy #141937, cream #EEEBDA. Text on ink = paper; on pink = ink.
Type:    Display = Roboto Condensed 900 uppercase, tracking -0.03em, lh .86–.9
         Editorial = Cormorant Garamond 300 (upright; italic only for 1–2 words)
         UI/body = Inter 400/500/600. t-ui = 12–13px uppercase +0.04em.
Radii:   0 everywhere. Hairlines 1px at 15–20% opacity.
Easing:  --ease-out-expo cubic-bezier(.16,1,.3,1); --ease-in-out-quart.
Depth:   perspective 1200–1600px; never more than 18deg of tilt; no drop
         shadows on text; media may cast one soft shadow on paper only.

4. THE CENTREPIECE: "КЛЮЧОВІ ВЕКТОРИ СИСТЕМИ" (#wheel) — FULL REBUILD
--------------------------------------------------------------------------------
Problem now: flat list of words with opacity steps, discrete jumps, empty right
half, no media, animation feels cheap.
Target: a real 3D word cylinder + cinematic media stage, scroll-linked and
butter-smooth.

Desktop (>=1024px, motion allowed):
- Section height = 100svh + 6 x 60svh. Inner stage is sticky, 100svh.
- Header row: kicker "Архітектура маркетингу" (pink) + h2 "Ключові вектори
  системи" left; big tabular counter "01 / 06" right.
- LEFT (7 cols): a CSS 3D cylinder. Container perspective 1400px. A
  preserve-3d <ul>; item i is placed with rotateX(-i*θ) translateZ(R) where
  θ = 22deg and R = row / (2*tan(θ/2)). The cylinder rotates rotateX(p*θ)
  where p is CONTINUOUS scroll progress (0..5), lerped in rAF (factor ~0.12)
  and written straight to the DOM through refs (no React re-render per frame).
  Per-item opacity = clamp(cos(delta*θ)^3), backface hidden; the front word is
  paper, the others paper at falling opacity — depth does the work, no
  outline text, no scaleY hacks.
  A thin pink "selection window" (two 1px rules + index) frames the front row.
- RIGHT (5 cols): a media stage (aspect 4/5) with one layer per vector
  (photo or muted looping video). The active layer reveals with clip-path
  inset(100% 0 0 0) -> inset(0) over 900ms expo while scaling 1.08 -> 1.0;
  only the active video plays. Under it: tag (pink t-ui), serif headline,
  description, CTA "Отримати стратегію" + "США • Європа • Україна".
- Progress rail: six clickable ticks; clicking scrolls smoothly to that
  vector's position (keyboard accessible, aria-current on the active one).
Mobile / reduced motion:
- No pin, no 3D. Horizontal scroll-snap rail of 6 cards (82vw): media 4/5,
  big display word, tag, headline, description, CTA. Counter shows position.
Accessibility: words are buttons (aria-pressed), the detail is a polite live
region, all media is decorative except where it carries meaning.

--------------------------------------------------------------------------------
6. MOTION SPEC
--------------------------------------------------------------------------------
- Reveal: line-mask translateY(105%) -> 0, 900ms expo, 70ms stagger.
- Media enter: clip-path + scale 1.08 -> 1, 1000ms expo.
- Scroll-linked: only transform/opacity, rAF + lerp, passive listeners,
  IntersectionObserver to start/stop work off-screen.
- Hover: 300–500ms; tilt follows pointer with lerp, resets on leave.
- Reduced motion (OS or manual switch): no pin, no tilt, no reel drift,
  no autoplay video (poster only), reveals are instant.
